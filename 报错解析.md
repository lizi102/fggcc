## 详细解释与解决方案 / Detailed Explanations & Solutions

### 100 模块缺失 / Missing Module

**含义 / Meaning**  
PyInstaller 打包时找不到某个 Python 依赖模块。  
PyInstaller cannot find a required Python dependency module during packaging.

**常见原因 / Common Causes**  
- 代码中 `import` 了某个第三方库，但未在打包环境中安装  
  A third-party library is imported in the code but not installed in the packaging environment.
- 使用 `--onefile` 模式时部分依赖未能正确打包  
  Some dependencies are not properly bundled when using `--onefile` mode.

**解决方案 / Solutions**
1. 在终端执行 `pip install 模块名` 安装缺失模块  
   Run `pip install module_name` to install the missing module.
2. 在 PB 中尝试添加 `--hidden-import=模块名` 参数  
   Add `--hidden-import=module_name` in PB.
3. 检查是否有拼写错误  
   Check for typos.

---

### 101 文件缺失 / Missing File

**含义 / Meaning**  
打包过程中找不到代码里引用的某个文件（如图片、字体、配置文件等）。  
A file referenced in the code (e.g., images, fonts, config files) cannot be found during packaging.

**常见原因 / Common Causes**  
- 引用了相对路径文件，但打包后路径结构发生变化  
  Relative file paths are used, but the directory structure changes after packaging.
- 文件未被正确打包到 exe 中  
  The file is not properly bundled into the exe.

**解决方案 / Solutions**
1. 使用 `os.path.dirname(__file__)` 动态获取文件路径  
   Use `os.path.dirname(__file__)` to dynamically get file paths.
2. 在 PB 的“附加文件”中添加该文件  
   Add the file in PB's "Additional Files".
3. 将资源文件放在项目根目录，并使用相对路径引用  
   Put resource files in the project root and use relative paths.

---

### 102 权限不足 / Permission Denied

**含义 / Meaning**  
当前用户没有权限写入目标目录或读取某个文件。  
The current user does not have permission to write to the target directory or read a file.

**常见原因 / Common Causes**  
- 输出目录在系统保护文件夹（如 `C:\Program Files`）  
  Output directory is in a system-protected folder (e.g., `C:\Program Files`).
- 当前用户不是管理员  
  The current user is not an administrator.
- 文件被其他程序占用  
  The file is being used by another program.

**解决方案 / Solutions**
1. 更换输出目录到用户文件夹（如 `D:\` 或 `桌面`）  
   Change output directory to a user folder (e.g., `D:\` or `Desktop`).
2. 以管理员身份运行 PB 打包器  
   Run PB Packager as administrator.
3. 关闭占用文件的程序后重试  
   Close the program using the file and retry.

---

### 103 Python 环境错误 / Python Environment Error

**含义 / Meaning**  
PyInstaller 找不到 Python 解释器或版本不兼容。  
PyInstaller cannot find the Python interpreter or the version is incompatible.

**常见原因 / Common Causes**  
- Python 环境被移动或卸载  
  Python environment has been moved or uninstalled.
- 使用了不兼容的 Python 版本  
  Using an incompatible Python version.

**解决方案 / Solutions**
1. 重新选择 Python 环境路径  
   Reselect the Python environment path.
2. 确保 Python 3.8 及以上版本  
   Ensure Python 3.8 or above.
3. 重新安装 Python 并重新选择环境  
   Reinstall Python and reselect the environment.

---

### 104 Qt 平台错误 / Qt Platform Error

**含义 / Meaning**  
PyQt5 相关的平台插件缺失，导致 GUI 程序无法启动。  
PyQt5 platform plugins are missing, causing the GUI application to fail to start.

**常见原因 / Common Causes**  
- PyQt5 的 `plugins` 文件夹未被正确打包  
  The PyQt5 `plugins` folder is not properly bundled.
- Qt 环境变量未正确设置  
  Qt environment variables are not correctly set.

**解决方案 / Solutions**
1. 在 PB 的“附加文件”中添加 PyQt5 的 `platforms` 文件夹  
   Add the PyQt5 `platforms` folder in PB's "Additional Files".
2. 在代码中添加 `os.environ["QT_QPA_PLATFORM_PLUGIN_PATH"]` 设置  
   Add `os.environ["QT_QPA_PLATFORM_PLUGIN_PATH"]` in your code.
3. 确认 PyQt5 已完整安装  
   Confirm PyQt5 is fully installed.

---

### 105 DLL 加载失败 / DLL Load Failed

**含义 / Meaning**  
缺少必要的系统动态链接库（如 Visual C++ Redistributable）。  
Missing required system DLLs (e.g., Visual C++ Redistributable).

**常见原因 / Common Causes**  
- 系统缺少 VC++ 运行库  
  VC++ runtime libraries are missing.
- OpenGL 或其他图形库缺失  
  OpenGL or other graphics libraries are missing.

**解决方案 / Solutions**
1. 安装 [Visual C++ Redistributable](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)  
   Install Visual C++ Redistributable.
2. 检查是否缺少特定 DLL 文件  
   Check if specific DLL files are missing.
3. 尝试使用 `--add-binary` 手动添加 DLL  
   Try manually adding DLLs with `--add-binary`.

---

### 106 资源文件丢失 / Resource File Missing

**含义 / Meaning**  
程序引用的图标、图片、字体等资源未被打包。  
Icons, images, fonts, or other resources referenced by the program are not bundled.

**常见原因 / Common Causes**  
- 资源文件未添加到“附加文件”列表  
   Resource files were not added to the "Additional Files" list.
- 资源路径在打包后发生变化  
   Resource paths change after packaging.

**解决方案 / Solutions**
1. 在 PB 的“附加文件”中添加上所有资源文件  
   Add all resource files in PB's "Additional Files".
2. 使用 `sys._MEIPASS` 获取打包后的临时路径  
   Use `sys._MEIPASS` to get the temporary path after packaging.
3. 确保资源文件名和路径正确  
   Ensure resource file names and paths are correct.

---

### 107 其他异常 / Other Exception

**含义 / Meaning**  
未被以上分类覆盖的错误。  
Errors not covered by the above categories.

**常见原因 / Common Causes**  
- 代码中存在逻辑错误  
   Logical errors in the code.
- PyInstaller 版本兼容性问题  
   PyInstaller version compatibility issues.
- 操作环境特殊  
   Special operating environment.

**解决方案 / Solutions**
1. 取消勾选“隐藏控制台”，重新打包  
   Uncheck "Hide Console" and repack.
2. 双击 exe 查看具体报错信息  
   Double-click the exe to see the specific error message.
3. 在 GitHub 仓库提交 Issue，附上日志  
   Submit an Issue on GitHub with the log attached.
