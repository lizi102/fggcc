# PB 打包器 / PB Packager

一个基于 PyQt5 + PyInstaller 的图形化 Python 打包工具。  
A graphical Python packaging tool based on PyQt5 + PyInstaller.

---

## 功能 / Features

- 图形化界面，无需命令行
- 支持单文件 / 多文件模式
- 支持自定义图标（.ico / .png / .jpg）
- 支持附加文件打包
- 打包进度条实时反馈
- 自动保存配置，记住上次路径
- 打包完成后自动打开输出目录
- 便携版，无需安装，删除即卸载

---

## 系统要求 / Requirements

- Windows 7 / 8 / 8.1 / 10 / 11（64 位）
- Python 3.8+（需提前安装）

---

## 下载 / Download

前往 [Releases](https://github.com/lizi102/fjgcc/releases) 下载最新版本。

---

## 使用说明 / How to Use

1. 选择要打包的 `.py` 文件
2. 选择输出目录
3. 点击“开始打包”
4. 等待打包完成，自动打开输出目录

---

## 配置文件 / Config

配置文件保存在：`%APPDATA%\PB\config.json`

# PB Packager

A graphical Python packaging tool based on PyQt5 + PyInstaller.

---

## Features

- Graphical interface, no command line required
- Supports single-file / multi-file mode
- Supports custom icons (.ico / .png / .jpg)
- Supports additional file bundling
- Real-time packaging progress bar
- Auto-saves configuration, remembers last used paths
- Automatically opens output directory after packaging
- Portable version: no installation required, delete to uninstall

---

## System Requirements

- Windows 7 / 8 / 8.1 / 10 / 11 (64-bit)
- Python 3.8+ (must be pre-installed)

---

## Download

Get the latest version from [Releases](https://github.com/lizi102/fjgcc/releases).

---

## How to Use

1. Select the `.py` file you want to package
2. Choose an output directory
3. Click "Start Packaging"
4. Wait for completion — the output folder will open automatically

---

## Config File

Configuration is stored at: `%APPDATA%\PB\config.json`
